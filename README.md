An execution machine built from one premise — there is no physical
code/data distinction — in five layers: resident roads, self-routing
tagged data, arrangement-only residency, circulation with
intermediates dying in registers, and exits-only boundaries. Specified
in `MACHINE.md` from its owner's own words, derived in `DERIVATION.md`,
preserved in `SOUL.md`, and built under the mechanical gates of
`BUILD-LAW.md` (`./lawcheck.sh` must pass before any number is real).

Current, lawful, measured on real traffic: routing, circulation, and
fan-out each beat their strongest conventional opponents with coded
verdicts and disjoint ranges; the full machine is depth-flat where
every opponent scales. Full record, architecture, findings, and open
work: `STATE.md`. Agent orientation: `CLAUDE.md`.

Reproduce everything on any Linux box with gcc + python3:
